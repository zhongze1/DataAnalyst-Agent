# 演示录制脚本与截图清单

> 用途：你按本文录一段演示视频、并按清单补齐 `docs/images/` 下的截图，再回填到
> [README.md](../README.md) 的「界面截图」一节。
> 文中所有"预期"都已在本项目的交付验证中实测过；若某一步与预期不符，先记为问题而不是跳过。

## 0. 录制前准备

```bash
# 1) 起服务（真实模型，演示效果最好；mock 模式画面一样但没有真实分析）
uv run uvicorn main:app --port 8000

# 2) 浏览器打开 http://127.0.0.1:8000
# 3) 用 .env 里配的管理员账号登录
```

准备素材：

- 上传用的数据集：`data/samples/电商平台订单_2024.xlsx`（3 张工作表、3600 行，最能体现"多工作表 + 异常提示"）。
- 建议把浏览器缩放定为 **100%**，窗口 **1440×900** 以上，关闭无关标签页与通知。

⚠️ **录制注意**：

- **不要**展示 `.env`、终端里的 API Key、`data/audit/*.jsonl` 原文（里面有真实调用记录）。
- 演示用的数据集是脚本用固定种子生成的**模拟数据**，可以放心展示；但仍建议不要展示任何真实客户数据。
- 想演示"敏感字段打码"，用 `data/samples/电商平台订单_2024.xlsx` 的「客户主数据」（含手机号列）。

## 1. 分镜脚本（建议总时长 4~6 分钟）

| 镜 | 画面 | 操作 | 预期 | 建议时长 |
| --- | --- | --- | --- | --- |
| 1 | 登录页 | 输入管理员账号口令 → 登录 | 进入主界面 | 10s |
| 2 | 主界面（空状态） | 鼠标掠过左侧上传区与右侧对话区 | 空状态提示"请先上传 Excel 文件" | 8s |
| 3 | 上传 | 拖入 `电商平台订单_2024.xlsx` | 显示文件名、大小、**3 张工作表** | 12s |
| 4 | 首次提问 | 输入「订单一共多少？毛利率大概多少？」并回车 | 结论先行（数字 + 口径）；**不出现代码** | 40s |
| 5 | 展示过程 | 点开「执行过程」，展开 `list_sheets` / `load_sheet` / `run_pandas` 每步 | 每步能看到调了什么工具、入参、返回的表格片段 | 35s |
| 6 | 多工作表 | 提问「商品品类销售额 Top3 是什么？」 | Agent 自行切到 `商品主数据`/`订单明细` 计算（过程里能看到 `load_sheet`） | 45s |
| 7 | 异常提示 | 提问「数据里有没有异常或需要剔除的记录？」 | 主动提示：超大批量订单 2 笔、重复订单号 1 笔、已取消订单 194 笔 | 45s |
| 8 | 陷阱式口径 | 提问「不同会员等级的消费能力有差异吗？」 | 说明**总销售额**与**人均**两个口径结论不同（人均更有意义） | 45s |
| 9 | 知识库检索 | 提问「DA-015 里敏感字段是怎么打码的？」 | 回答引用**文档名 + 章节 + 行号**，只给结论不粘贴大段原文 | 45s |
| 10 | 连续追问 | 接着追问「那导出的时候也会打码吗？」 | 沿用同一会话上下文继续回答 | 30s |
| 11 | 导出报告 | 点导出 → 打开下载的 Markdown/Excel | 产物含结论、数据明细、执行轨迹 | 30s |
| 12 | 持久化 | **刷新页面**（必要时重启服务） | 历史会话仍在，点开能看回完整问答 | 20s |
| 13 |（可选）多用户隔离 | 退出 → 用另一个账号登录 | **看不到**别人的会话；直接访问别人的会话 ID 得到 404 | 30s |
| 14 |（可选）配额提示 | 连续快速提问把每分钟额度打满 | 出现限流提示与建议等待时间（429 + `Retry-After`） | 25s |

**口播要点（3 句就够）**：

1. 它不猜数字 —— 每一步都是真实调用工具算出来的，过程可展开、可审计。
2. 它知道自己**只查项目文档、不查你的表**；查不到就说查不到。
3. 对外展示的敏感字段会自动打码，但喂给模型的是原文 —— 否则算出来的结果会错。
